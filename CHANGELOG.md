# Prued FX 2.0.0 — Windows

Released for Windows on 23 October 2026. Creator accepted the Windows RC2 build.

- The original Stutter knob now controls performance looping, repeat rate and intensity.
- Beat sync, loop recapture and smooth crossfades improve live transitions.
- Fixed cumulative vertical drift when turning the filmstrip knobs.
- Fixed the Bypass click target, indicator updates and DAW bypass integration.
- Preserved the released interface, artwork, original parameter IDs and preset loading. The three existing numeric readouts use larger text.
- Free use lasts 15 minutes per plugin instance. At expiry, audio fades back to dry. Remove and reinsert the plugin to restart the trial.
- A Gumroad license key unlocks unlimited use in the same plugin. Right-click the editor to activate.

Windows x64 VST3. macOS 2.0 source/build preparation is available on the development branch; no macOS 2.0 binary is released yet.
